# J.A.R.V.I.S. Hand Control

Управление компьютером жестами рук через обычную веб-камеру (Windows).
Работает на Google MediaPipe: модель находит 21 точку на каждой руке.

## Запуск

Дважды щёлкните **`run.bat`**. При первом запуске он сам поставит зависимости.

Справа внизу появится окно с изображением камеры. Оно всегда поверх остальных окон.

| Клавиша | Действие |
|---|---|
| **F9** | пауза / продолжить (работает в любом окне) |
| **H** | подсказка по жестам |
| **Q** / **Esc** | выход (окно камеры должно быть активным) |

Параметры командной строки: `run.bat --dry-run` — только показывать, мышью не управлять; `--camera 1` — другая камера; `--right-handed` — мышь управляется правой рукой, команды — левой.

## Чувствительность и режим курсора

| Клавиша | Действие |
|---|---|
| **F8** | чувствительность выше (в любом окне; в окне программы также **+**) |
| **F7** | чувствительность ниже (в любом окне; в окне программы также **−**) |
| **M** | переключить режим «тачпад» / «рамка» (в окне программы) |

Текущий режим и чувствительность показаны в строке внизу окна. Изменения сохраняются автоматически.

- **Тачпад** (по умолчанию). Курсор сдвигается вслед за рукой, а не привязан к её положению в кадре. Скорость курсора зависит от скорости руки:
  - **медленно** — курсор идёт медленно и точно (5% кадра ≈ 100 пикселей);
  - **резко** — курсор пролетает большие расстояния (15% кадра ≈ полэкрана), поэтому руку достаточно держать в небольшой области;
  - **неподвижная рука** — курсор стоит на месте, дрожание игнорируется;
  - **прицеливание** — когда большой и указательный почти сведены перед кликом, курсор замедляется примерно втрое (внизу появляется «прицеливание»). Если рука упёрлась в край кадра, уберите её из кадра, верните в центр и покажите ладонь снова, как будто подняли палец с тачпада.
- **Рамка**. Положение руки в рамке на картинке соответствует положению курсора на экране. Чем выше чувствительность, тем меньше рамка.

## Жесты

**Чтобы рука начала управлять, покажите камере открытую ладонь.** Пока вы этого не сделали, рука на мышке или клавиатуре ничего не трогает. Если рука уйдёт из кадра, при возвращении снова нужно показать ладонь.

### Левая рука — мышь
| Жест | Действие |
|---|---|
| Открытая ладонь, двигать | курсор (следует за центром ладони) |
| Щипок **большой + указательный**, сразу развести | левый клик. Два быстрых щипка — двойной клик |
| Щипок **большой + указательный** и вести руку | перетаскивание |
| Щипок **большой + указательный**, держать неподвижно 0,6 с | правый клик |
| Щипок **большой + средний** | тоже правый клик |
| **Кулак** + двигать руку | прокрутка вверх/вниз/вбок («тянешь страницу») |
| Щипок **большой + мизинец**, держать 1 сек | пауза / продолжить |

### Правая рука — команды
| Жест | Действие |
|---|---|
| Щипок **большой + указательный** + вверх/вниз | громкость |
| Щипок **большой + средний** | скриншот области (Win+Shift+S) |
| **Кулак** | пауза / воспроизведение музыки или видео |
| Свайп ладонью **влево / вправо** | предыдущий / следующий рабочий стол |
| Свайп **вверх** | все окна (Win+Tab) |
| Свайп **вниз** | свернуть всё (Win+D) |

## Советы для точности
- Сядьте в 50–80 см от камеры, чтобы рука помещалась в кадр целиком.
- Нужен ровный свет спереди. Яркое окно за спиной мешает.
- Двигать нужно в зоне, отмеченной рамкой на изображении камеры. Она растягивается на весь экран.
- При щипке курсор «замирает», поэтому клики попадают точно. Перетаскивание начинается, когда рука сдвинется.

## Настройка (`config.json`, создаётся при первом запуске)
| Параметр | Что делает |
|---|---|
| `active_region` | зона кадра для курсора. Чем она меньше, тем выше чувствительность |
| `smooth_min_cutoff` | меньше — курсор плавнее, но с задержкой |
| `smooth_beta` | больше — курсор быстрее реагирует на резкие движения |
| `gain_slow` / `gain_fast` | скорость курсора при медленном / быстром движении руки (режим тачпада) |
| `deadzone` | порог дрожания: больше — курсор устойчивее, но хуже реагирует на очень мелкие движения |
| `precision_gain` | во сколько раз замедляется курсор при прицеливании (0.35 ≈ втрое) |
| `pinch_on` / `pinch_off` | насколько близко сводить пальцы для щипка и насколько разводить для отпускания |
| `scroll_speed`, `natural_scroll` | скорость и направление прокрутки |
| `volume_step` | какое движение руки меняет громкость на 1 шаг |
| `swipe_distance` | длина свайпа |
| `primary_hand` | `"Left"` (по умолчанию) или `"Right"` — какая рука управляет мышью |
| `camera_width` / `camera_height` | разрешение камеры. Меньше — быстрее |
| `actions` | сочетания клавиш для жестов левой руки, например `"ctrl+win+right"`, `"alt+tab"`, `"play_pause"`, `"volume_mute"` |

В `config.json` сохраняются только изменённые настройки. Чтобы вернуть всё по умолчанию, удалите файл.

## Ограничения
- Не работает в окнах, запущенных от имени администратора, если сама программа запущена без прав администратора. Это ограничение Windows.
